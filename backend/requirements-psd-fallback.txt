# SUPERSEDED 7 Aug 2026 — do not install this file. It is kept only so existing instructions and
# scripts that reference it do not silently install a *second*, unpinned pytoshop alongside the
# pinned one.
#
# `pytoshop==1.2.1` now lives in requirements.txt, where it belongs.
#
# Why the original split was wrong: this file existed so a failed Cython build could not block the
# imaging core. That reasoning was sound, but the consequence was not — Adobe Firefly is
# enterprise-quoted and never landed, so the pytoshop writer is the ONLY path that ships a PSD.
# Keeping it optional meant layered PSD did not work at all, and the two PSD test suites *skipped*
# rather than failed, so nothing reported the outage. See docs/PSD.md.
#
# The original concern is now handled properly instead: app/psd/fallback.py guards its import, so a
# machine where the build fails raises a typed `psd_unavailable` on PSD jobs while every other
# output format keeps working. That is what "must not block the imaging core" should always have
# meant.
#
# To install dependencies, use:
#   pip install -r requirements.txt
